# الاختبارات والقياسات

## تشغيل الاختبارات

```bash
cd backend
.venv\Scripts\python -m pytest                                   # سريعة، بدون نماذج أو صوت
set RUN_MODEL_TESTS=1 && .venv\Scripts\python -m pytest          # + النماذج الحقيقية على كرت الشاشة
set RUN_AUDIO_TESTS=1 && .venv\Scripts\python -m pytest          # + التقاط صوت حقيقي (يصدر صفيرًا خفيفًا)
```

الاختبارات لا تلمس إعداداتك ولا سجلك الحقيقي أبدًا، لأن كل اختبار يعمل في مجلد مؤقت (`tests/conftest.py`).

## ماذا تغطي

| المجال | أمثلة على ما يُختبر |
|---|---|
| الصوت | تحويل الصيغ، وتحويل معدل العينات **بلا تشوه عند حدود القطع** (−٩١ ديسيبل مقابل −٣٤ في الطريقة الخاطئة)، وقص الصمت، والمشغّل وخفض الصوت |
| كشف الكلام | جملة واحدة، وقفة قصيرة لا تقسم، وقفة طويلة تقسم، أوضاع السرعة، تجاهل الطقطقات، القطع الإجباري عند أهدأ نقطة، النص الجزئي، الإيقاف |
| اللغات | كل رموز اللغات الـ١٠٣ موجودة فعلًا في نموذجَي الفهم والترجمة، والاكتشاف التلقائي مع خطته البديلة |
| الترجمة | جملة بجملة، المرور المباشر لنفس اللغة، ar↔de وen→de حقيقية |
| الصوت المولَّد | سماع الصوت الناتج مرة أخرى بـWhisper للتأكد أنه مفهوم، ومستوى الصوت، والسرعة، و**التحويل لنص فقط** عند غياب الصوت |
| المحرك المتواصل | كل جملة تُترجم مرة واحدة، والتراكم يتحول لنص بدل التأخر، والكتم والإيقاف يلغيان المنتظر، والأخطاء لا توقف البرنامج |
| الجلسة الكاملة | توجيه كل اتجاه لمكانه الصحيح، والمقاطعة، والإيقاف المؤقت، وإعادة آخر ترجمة، و**محادثة حقيقية عربي↔ألماني بالنماذج** |
| التقاط الاجتماع | التقاط برنامج واحد بدقة، و**عدم التقاط صوت برنامجنا أبدًا** (ضمان عدم الصدى) |
| الخادم والواجهة | رفض أي طلب بدون الرمز السري، والتحقق من الإعدادات، والسجل مقفول افتراضيًا، و**WebSocket حقيقي** |
| التنزيلات | خطة جهاز بدون كرت شاشة، والتنزيل وفك مكتبات NVIDIA، والإبلاغ عن انقطاع الإنترنت |

## القياسات الفعلية (RTX 5060 Laptop، 2026-10-03)

| القياس | النتيجة |
|---|---|
| فهم ٢٫٨ ثانية كلام (large-v3-turbo، GPU) | ٠٫٥–٠٫٦ ثانية |
| ترجمة جملة (NLLB 1.3B int8، GPU) | ٠٫١١–٠٫١٨ ثانية |
| أول صوت مترجم بعد نهاية جملة ألمانية (صوت عربي) | ١٫٠٤ ثانية |
| **من لحظة سكوت المتكلم حتى سماع الترجمة**، شاملًا انتظار ٠٫٦ ثانية للتأكد من نهاية الجملة | **١٫٤–١٫٦ ثانية** |
| نفس الشيء على المعالج فقط (large-v3-turbo، بلا GPU) | ٩–١٩ ثانية، ولذلك تختار الأجهزة بلا كرت شاشة نموذج `small` تلقائيًا |
| التشكيل العربي التلقائي | ٧ ميلي ثانية |

**ملاحظة صادقة:** لم أختبر الدقة على صوت بشري حقيقي بلهجات مختلفة. ملفات الاختبار مولَّدة صناعيًا،
لأن الميكروفون كان مكتومًا وقت التطوير. المطلوب منك: جمل حقيقية بالعامية المصرية وبالألمانية، ثم قياس الأخطاء.

## خطة الاختبار اليدوي (قبل كل إصدار)

اختبر هذه الأزواج: عربي↔إنجليزي، عربي↔ألماني، عربي↔فرنسي، في الاتجاهين. ولكل زوج:
- كلام سريع، وكلام بطيء، وجمل قصيرة («تمام»، «Ja»)، وجمل طويلة (أكثر من ١٥ ثانية).
- ضوضاء: مروحة، وموسيقى في الخلفية.
- لهجات: مصري، وشامي، وخليجي.
- متحدثون متعددون بالتناوب بلغات مختلفة (اكتشاف تلقائي).
- مقاطعة: الطرف الآخر يتكلم أثناء نطق ترجمتك.
- انقطاع: افصل الإنترنت (يجب ألا يتأثر شيء)، وافصل السماعة أثناء التشغيل.
- صدى: جرّب بدون سماعة رأس مع إلغاء «أستخدم سماعة رأس».

## ما يُقاس في كل تجربة
زمن الوصول (يظهر تحت كل رسالة في الواجهة)، والرسائل التي تحولت لنص فقط (`dropped_to_text`)،
والأخطاء (`errors`)، واستهلاك المعالج والذاكرة من مدير المهام، وسجل البرنامج في
`%APPDATA%\AI Live Translator\logs\engine.log`.
